# 托业阅读提分 v2 · 设计说明（接手用）

## 1. 产品原则
- 用最少注意力和时间涨 Reading 分。职场外壳只服务分数：一句职场反馈 + 职级，非答题时间 ≤10%。
- 闭环：入职诊断 → 针对训练（薄弱点）→ 间隔复习 → P5→P6→P7 混合 → 整套模考验证。
- 用户只做一个选择：5 / 20 / 75 分钟。
- 只支持现行新制（75 分钟 100 题：P5 30 / P6 16 / P7 54）。
- 中文界面、大白话；先产品体验，后技术。

## 2. 界面清单
底部 Tab（答题/结算时隐藏）：
| Tab | 内容 |
|---|---|
| 工作台 | 预测阅读分 + 区间条（含目标刻度）、达标概率、连续打卡、今日题数、距考试天数；任务卡 5/20/75 分钟；未完成会话"继续"；未诊断时置顶诊断入口 |
| 薄弱点 | 考频 × (1−掌握度) 前 15，每行"攻克" |
| 复习 | 到期错题复习（≤20）、背生词（认识/模糊/不认识）、错题本（重做）、生词本（删） |
| 图谱 | 305 节点按 6 层折叠，分组节点作小标题，叶子节点显示掌握度条或"未测" |
| 我的 | 档案新建/切换/删除；目标、考试日期；进度码生成复制/导入为新档案；导出作答日志（JSON 下载）；本周 PK；模考记录；重置 |

其他视图：入职登记（档案名、目标 600/700/800/900、考试日期）、答题器、模考、结算/模考报告、底部弹层（工作规则卡、生词卡）。

### 答题器
- P5 单题；P6/P7 按 bundle：原文卡片可收起；多篇用"文1/文2/文3"切换；P6 空位 `{{题号}}` 行内显示，当前题高亮。
- 计时条：当前题用时 / target_time_sec，超时变红。
- 练习工具（训练/攻克/复习可用；诊断、模考不可用）：稍后处理（单题移到末尾 / bundle 内移到本组末尾）、划依据（点句高亮，按 bundle 记）、点词进生词本（记例句；本题记为"查词"）。
- 答后：一句职场反馈、正确答案、用时 vs 目标、explain_zh、所选干扰项 why_zh（pilot 题才有）、考点名；同主节点连错 ≥2 次出"看工作规则卡"按钮（技巧库中绑定该节点或其父节点、practice_mode=true 的前 2 条）。
- 诊断：答完直接下一题，不给反馈，最后出结果。

### 模考
- 选未用过、且已练过题最少的 xdf 套（T01–T10；部分套因原文缺图少于 100 题）。
- 75 分钟倒计时（绝对截止，暂停不停表），无工具无反馈；上一题/下一题、题号导航（已答着色）、交卷确认；时间到自动交卷。
- 交卷后统一记分（未答按错），报告：换算分、各 Part 对题数、结算项。该套记入 `used`，此后不进训练池。

### 结算
题数、正确率、用时 vs 目标总和、预测分变化、涉及主节点涨跌（各前 4）、职级（变化时提示晋升）。

## 3. 引擎算法（engine.js）
### 掌握度（Elo 式）
- 难度 b = (difficulty_est − 3) × 0.7（logit）。
- 全局能力 th：th += Kg·(r − σ(th − b))，Kg = max(0.06, 0.6/(1+0.05N))。
- 节点 θ：首次触达用当前 th 初始化；主节点 K = max(0.15, 0.8/(1+0.1n))，其他 node_ids 用 K/2。掌握度 = σ(θ)。

### 预测阅读分
- 期望正确率 = 在难度分布 b∈{−1.4,−0.7,0,0.7,1.4}（权重 .1/.25/.35/.2/.1）上平均 σ(th−b) → 原始分 0–100 → 分段线性换算表（SCALE）→ 5–495，取 5 的倍数。
- 区间半宽 = max(20, 150/√(1+N/8))，随作答收窄。
- 目标：阅读目标 = 总分目标 / 2（600→300 … 900→450）。达标概率 = Φ((预测−目标)/(半宽/1.645))（logistic 近似）。
- 职级：<200 实习生，200 专员，300 主管，375 经理，430 总监。

### 简化 FSRS（题卡与词卡）
- 快对（用时 ≤ 目标）间隔 ×2.5；慢对 ×1.3；错或本题查过词 → 1 天。
- 新题快对且没查词：不建卡（已会，不浪费复习）；其余都建卡，错题进错题本。
- 生词：认识 ×2.5，模糊 ×1.3，不认识 → 1 天。
- 每日复习上限约一半：5 分钟卡最多 4 道复习（共 8）、20 分钟卡最多 10 道（共约 20）；复习页一次最多 20。

### 选题
- 薄弱点得分 = exam_weight × (1 − 掌握度)；未测节点用全局能力并 ×0.9。
- 5 分钟：到期 P5 复习 ≤4 + P5 薄弱题补到 8。
- 20 分钟：复习 ≤10 + P5 ×8 + P6 1 篇 + P7 单篇 1 组（都偏向前 6 薄弱节点）。
- 单题排序：未做优先、|b − th| 小优先、加随机扰动。
- 攻克：该节点 P5 ×6 + 含该节点的 P6/P7 各 1 组（题库有才出）。
- 诊断：pilot P5 难度 2,2,3,3,4,4 各 1 + pilot P6 一篇（4 题）+ pilot P7 单篇（≤3 题）≈ 12–13 题。

### 日志
所有动作写 `log`（上限 2 万条），可导出 JSON。进度码不含日志（体积）。

## 4. 存储
- Store：先试 localStorage（写读测试），失败或写入时配额满 → 内存运行，顶部横幅提示复制进度码。
- 预留 SupabaseAdapter：实现 get/set/del 同接口即可；当前不联网。
- 进度码 = base64(UTF-8 JSON {app:'toeic-r-v2', name, st})，导入总是新建档案，不覆盖。

## 5. 已知问题 / 待验证
- 未做真机和浏览器截图验证（环境无无头浏览器）；只做了 node DOM 桩冒烟测试。
- 预测分换算表、阅读=总分/2 都是近似，需模考校准。
- xdf 题难度一律 3、节点为规则粗打；干扰项错因只有 pilot 题有。
- 模考可能包含训练里做过的题（选练过最少的套来缓解）。
- 点词只收词不查义（无离线词典）。
- 图谱 Tab 一次渲染 305 行，低端机可能稍慢。
