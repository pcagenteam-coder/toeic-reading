# 预测分模块校准（C3，`app/src/predict.js`）

**方法**：3PL（c=0.25）分层 IRT（θg~N(0,1)，各 Part 偏移 δ~N(0,0.35²)，旧作答半衰期 45 天）→ 各 Part 期望正确率（难度分布取整套题）→ 75 分钟时间预算（个人用时比，超时题按 0.25 猜测）→ 原始分 → 量表分。
蒙特卡洛得期望分 T 的分布，加模型误设 σ=15；整套模考按精度加权（抽样误差 + 等化 10 + 每周漂移 6）；预测区间再加一次真实考试的二项抽样误差与等化误差 10。真实成绩 → 贝叶斯偏移（先验 N(0,30²)）。

**换算表（近似）**：原始分→量表分取公开流传的 TOEIC 阅读换算区间中位数（如 50→215、70→315、80→370、90→425、95→460），**非 ETS 官方固定表**，未逐表核对；ETS 每套卷等化，实际浮动约 ±10–20，已计入区间。

**模拟设置**（`node app/test/predict.test.js --full`，结果 `work/c3/sim_full.json`）：真实能力 θ~N(−0.3,1.2²)，Part 偏移 sd 0.3，用时比 lognormal(0.1,0.25)；练习题从训练池抽（3PL 生成，5% 对题查词）；“真实考试”= 计时做一套开源整套（MXT01–06），当天状态 sd 0.15、换算误差 sd 10。

真实成绩校准（考场能力系统性比练习低 0.4 的 400 名用户，200 题练习）：下一次考试 MAE 29.3 → 26.9，校准后覆盖 85.0%。

**局限**：误差下限 ~25 分主要来自一次考试本身的抽样噪声（≈±23）。模拟与模型同构（同一换算表、同一 3PL），真实误差会更大；题库 difficulty_est 未经真实作答标定；用时模型假设按题号顺序作答。上线后应用用户自报成绩复核覆盖率并调 σ_mis。
