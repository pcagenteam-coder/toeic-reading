# 产品简报：用户已定的原则与决策（接手必读）

总目标（用户原话）：让用户用最少的注意力和精力时间，不抵触的达成目标，也要给用户类似游戏的成就感和吸引力。游戏化只服务提分，非答题时间占比要小。

## 提分内核
- 先测当前能力；每题作答都更新能力评估，实时调整计划和下一题。
- 范围：现行新制 TOEIC（中国 2018-04 起；P5 30、P6 16、P7 单篇 29 + 多篇 25）。旧制技巧标 deprecated，不进图谱。
- 必须覆盖：题型、考察点、应试技巧；每题计时；5 分钟碎片 / 20 分钟标准 / 75 分钟全真模考。
- 薄弱点快速攻克；词汇/语法基础层。
- 记忆曲线：FSRS 管词、考察点、技巧；任务中使用即复习（快对/慢对/点词或错）；到期项写进次日内容；每日复习上限约一半；考前压缩间隔对准考试日；进度三层（对象状态/图谱/目标）。

## 体验外壳
- 职场模拟游戏外壳：入职诊断、收件箱（P7 邮件/群聊/通知）、改稿/审稿（P5/P6）、紧急任务（计时、模考）。v1 demo 是这个方向的样板；v2 功能全但场景被简化，需恢复。
- 用户不喜欢背单词学语法 → 潜移默化：词汇播种进邮件；审稿/秒审练语法；技巧变“工作规则”（先题后文、划依据、稍后处理、时间预算）；规则卡只在连错时可选弹出。
- 商务词汇量普遍低：按个人词汇量控制生词率 ≤5%；点词即查；渐隐注释；场景轮岗词包；商务常识卡。
- 进展分层：每题一句工作反馈；每场看预测分和薄弱点变化；每周“绩效评估”揭晓学到了什么。
- 中文界面，大白话。

## 数据
- 词汇以 NGSL 1.2 + TSL 1.2（CC BY-SA 4.0）为主，按目标分分层；新题用两个词表做超纲检查（专有名词、数字除外）。
- 自编题对标 ETS 官方样题格式，不复用 ETS 原文。
- 公开仓库只放原创和有明确开源许可的数据；无许可题库留私有（private_data/ + .gitignore）。ETS 转录只做模考/难度校准。
