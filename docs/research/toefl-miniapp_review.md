# 调研：huieric/toefl-miniapp（托福备考助手，MIT）2026-10-22

仓库：https://github.com/huieric/toefl-miniapp（Vue3 + Express + PostgreSQL，微信小程序骨架；约 60 个后端路由）。本地克隆在项目 research/toefl-miniapp。

## 值得借鉴
1. **完整 FSRS-4.5**（server/src/services/fsrs.js，167 行，无依赖，MIT）：S/D 双状态、17 个官方默认权重、目标保持率 0.9。我们现在是"间隔×2.5/×1.3"的简化版 → 直接移植（保留署名），改造两点：
   - 评分自动推断，不让用户自评：快对→Good(或 Easy)、慢对→Hard、错/查词→Again。减少操作和抵触。
   - 考前压缩：间隔上限 = 距考试天数的一部分；临考 2 周把目标保持率提到 0.95。
2. **Streak Freeze（断签保护）**：连续 3 天得 1 张、每天最多得 1 张，断签自动消耗。符合"不惩罚断签、坚持下去"。
3. **每日碎片学习**：每日一句、语境词、3–5 分钟挑战、周报。对应我们的 5 分钟任务和每周绩效评估。
4. **移动端阅读"文章/答题"一键切换**：和我们的手机单栏方案一致；平板/PC 再做左文右题分栏。
5. **用户自带资料（PDF 导入）规避版权**：内部版可考虑"导入自己的题库文件"，不由我们分发无授权题。

## 不要学
- 功能堆砌：60 个路由里很多是模拟数据（score-predictor、srs-review 等用写死的样例），没有真实闭环。我们坚持"少而闭环"。
- 预测分是假数据，不可参考；三阶段计划是固定模板（每天 60–180 分钟），不适合精力有限的成年人。
- 依赖服务器 + 数据库：我们保持离线单文件优先，云同步做可选。
