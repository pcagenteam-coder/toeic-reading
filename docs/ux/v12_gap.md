# UX v1.2 差距分析（prototype_v1 vs 线上 v1.1）
截图：work/ux12/cmp/{v1,d}_{m,pc}_{home,feedback,p7,p6}.png（390×844 / 1280×800），拼图 m_all.jpg、pc_all.jpg。

## v1 带来沉浸感/清晰感的东西
- 一进门就是「工作台 · Halvorsen」：分数+目标进度条、职级、距考试天数、今日任务按收益排序——知道自己在哪、今天干什么。
- 场景即题型：收件箱（Part 7，未读圆点、发件人头像、主题、附团队聊天）、改稿（Part 6，Draft 标题+编号空位）、紧急任务（限时群聊）。题目就是「老板问你：…」。
- 每题都有可见计时（0s 起跳，「目标 25 秒/60 秒」），节奏感=考场感。
- 作答后立刻判定：「✗ 答错（用时 1s）/ ✓ 答对」+ 正确答案 + 一句解析 + 掌握度变化 → 有明确对错和成就感。
- 测试结果直接写「答对 x / 8」。

## 当前版丢了什么
- 计时：v1.1 把计时环默认隐藏，也不显示每题秒数 → 没有节奏感、像在做阅读理解作业。
- 对错：答错只把选项描橙色、正确项描绿，文案只写「正确答案 (D)」，没有「答错了」字样；结算刻意不显示题数/正确率 → 不知道自己做得怎样。
- 沉浸：Part 7 只是普通文本+「From/To」小表格；群聊、公告与正文同一种排版；人物只在 2.5 秒淡出的副标题里露一下；P6 是平铺文章，看不出「改 Mia 的草稿」。
- 首页：v1.1 完成态只有「今天的活干完了」，没有工作台信息；分数折叠在「本周趋势」里。

## 入口混乱具体在哪
1. 「开始」按钮文案含糊，主按钮下又藏「今天时间多？˅」→「多做 15 分钟 / 紧急项目（全真模考）」，模考名称看不懂。
2. 专项练习叫「主管带你练（最快涨分）」，藏在「复习」tab 里，和「开始复习」两个按钮并列。
3. 模考有三处入口（今天页折叠、考前卡片两段、紧急项目），名字各不相同。
4. 「补测词汇」「作息提示」「提醒」卡片与主任务同级堆在首页。
5. 底部「我的」实际是设置+目标+数据，名字不直白。

## 新入口结构（v1.2）
- 首页「工作台」：唯一主按钮「开始今天的工作」，下面一行写「约 N 分钟 · 2 封邮件 · 6 句审稿 · 复习 3 个」；完成后主卡变「今天的工作完成 ✓」+ 次按钮「再做 5 分钟」。
- 主卡下「其他练习」列表（次级、直白名称，各一句说明）：复习到期题（N 个）→ 复习页；专项练习：最快涨分考点「X」→ 直接开练；全真模考（75 分钟，倒计时）；看进度。
- 词汇补测/作息/提醒等提示降为一行小提示，放在列表之后。
- 底部导航 4 个：今天（今天的工作和其他练习）/ 复习（错题和生词按记忆曲线回来）/ 进度（预测分、职级、本周小结）/ 设置（计时、字号、目标、数据）。
- 复习页只做复习（去掉专项练习按钮）；模考只从首页「其他练习」与考前卡片进入，统一叫「全真模考」。
