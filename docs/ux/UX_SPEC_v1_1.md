## 0. 北极星、内部指标与设计原则

### 0.1 北极星

> **让用户以最小努力和注意力达到托业阅读目标分。**（Qing 2026-10-23 再次确认）

- 后台用科学方法**替用户做决定**：FSRS 间隔重复（何时复习）、知识图谱 ROI（先学什么、学到哪为止）、考试技巧（考场怎么分配时间和放弃）。
- 前台只做三件事：**降低开始和坚持的抗拒、让人沉浸、让每一分钟都换成分数。**
- 用户：35–50 岁职场人，四六级多年前考过，精力少，不擅背词和语法。字号可调，但不默认大字。

### 0.2 v1 拍板项（Qing 已确认，全部按推荐）

| # | 决定 | 本文落点 |
|---|---|---|
| Q1 | 阅读目标 = 总分 − 听力估分；不填听力按 总分 × 0.45（取 5 的倍数） | §4 S1 |
| Q2 | 收件箱/改稿不设独立入口；导航 4 个入口 | §1 |
| Q3 | 完成任意一次任务即打卡（5 分钟到点或 ≥5 题） | §14 |
| Q4 | 词汇测试 = 认识/不认识 + 假词 + 少量四选一抽查，约 3 分钟 | §4 S3 |
| Q5 | 诊断完成即算第 1 天；当日 5 分钟任务可选 | §4 S6 |
| Q6 | 快对 0.8 秒自动跳题；灰色用时环，可隐藏 | §8.1、§7.8 |

### 0.3 内部北极星指标（不给用户看）

**每涨 1 分预测分花的分钟数（min/pt）。**

- 定义：滚动 14 天内，用户有效学习分钟（题目可见且 App 在前台的时间，含复习、讲解，不含剧情过渡与结算停留）÷ 同期预测阅读分中值的上涨量。
- 计算条件：预测区间宽 ≤ 80 分、窗口内 ≥ 4 个学习日、上涨量 ≥ 5 分；否则记“暂不可算”，不进统计。
- 用途：C2 排程 A/B、内容与交互改动的验收（改动后 min/pt 不升才保留）；产品看板按目标档、Part、设备分组。
- 次级护栏指标：7 日留存（周学习 ≥ 3 天的比例）、单次任务完成率、主动退出率、“记一招”收藏率、剧情过渡关闭率（> 30% 说明剧情在拖累）。
- **任何界面都不出现这个指标**；对用户只说“离目标还差 N 个考点，约 X 小时”（§11）。

### 0.4 设计原则（每屏用这 9 条检查）

1. **一屏一件事，一个主按钮。** 主按钮在拇指区（手机底部 1/3）。
2. **用户不做学习决策。** 学什么、复习什么、先后顺序、学到哪为止，全由系统按 ROI 定；用户唯一能改的是“今天多学一点”，而且默认不需要改。
3. **不让用户自评。** 记忆评分全部自动：快对=Good（很快=Easy）、慢对=Hard、错或查词=Again。
4. **够用就好。** 超出目标档的内容不进每日任务；技巧对用户只给作战卡（≤8 条）和错题时的“记一招”（每次 ≤1 条）。
5. **不惩罚。** 断签、做错、查词、跳过都不扣分；不出红色大叉、不出排名、不出“你已落后”。
6. **大白话 + 对比清晰。** 不出现 FSRS、节点、θ、logit、保持率、ROI；数字带对比：“18 秒（目标 25 秒）”。
7. **沉浸只服务分数。** “你在公司的一天”剧情文字每处 ≤ 1 行、不占独立屏、可关；阅读区内不出现任何装饰。
8. **任何时刻可退，不丢任何东西。**
9. **离线优先。** 首次装好后所有学习功能断网可用；同步只是附加。

## 1. 信息架构与导航

### 1.1 结构（4 个入口不变）

```
启动
├─ 首日：入职第一天（只走一次，可中途退出、下次接着走）            §4
│   目标与考试日期 → 入职词汇摸底(3 分钟) → 入职测试(约 5 分钟) → 结果+作战卡 → （可选）今天的活
└─ 主界面
    ├─ 今天 ：今天的活（你在公司的一天）· 一个主按钮 · 预测分一行            §5
    ├─ 复习 ：到期复习一键开始；待办复查 / 生词本 / 改写对 / 主管带你练      §10
    ├─ 进度 ：离目标还差 N 个考点·约 X 小时、预测区间、作战卡、绩效评估、紧急项目记录 §11 §12 §13
    └─ 我的 ：目标与日期、字号、剧情、个性化、提醒、数据、关于              §17
    做题页（全屏，隐藏导航）：审稿 P5 / 改稿 P6 / 收件箱 P7 / 紧急项目        §7 §12
```

- **打开 App 的落点**（降低开始成本，§2.1）：有未完成任务 → **直接回到做题页上次的位置**（顶部 1 行“接着上次 · 还剩约 2 分钟”，3 秒后自动收起）；没有 → “今天”页，屏上只有一个主按钮。
- “自己挑着练（按 Part）”保留在“复习”底部的次级入口，标“想自己练时用；系统安排的已经够了”。
- 剧情不改变导航：没有“公司”“收件箱”等额外入口，剧情只存在于“今天的活”内部、结算和周报里。

### 1.2 三端导航形态

| 端 | 断点（CSS 宽度） | 主界面导航 | 做题页 |
|---|---|---|---|
| 手机竖屏 | < 600px | 底部 4 Tab（图标+文字，高 56px） | 单栏；P6/P7 文章/题目一键切换 |
| 平板竖屏 / 大屏手机横屏 | 600–899px | 底部 4 Tab | 单栏加宽；P7 默认切换，可设“上下分屏” |
| 平板横屏 / PC | ≥ 900px | 左侧竖栏（宽 200px，可收成 64px） | 左文右题，默认 55/45，中缝可拖（40–70%） |

PC 主界面内容区最大宽度 960px 居中；做题页满宽，最大 1440px，≥1440 两侧留白。

### 1.3 全局元素

- **主界面顶部栏**：左“今天 · 10月23日 周五”，右“本周 3 天 ❄1”（本周学习天数为主、连续天数为次，点开看断签保护说明 §14）。
- **做题页顶部栏**：左“✕”（=暂停并保存，读屏标签“退出，进度已保存”），中进度点“3 / 8”，右用时环（§7.8）与“⋯”菜单（字号、剧情开关、稍后再做、键盘快捷键、报告题目问题）。
- **返回规则**：系统返回键/浏览器后退 = 上一层；做题页按后退 = 直接退出并保存，toast“已保存，随时接着做”，**不弹确认框**（v1 的二次确认取消：确认框本身就是阻力，而进度不会丢）。
- **Toast**：底部 2 秒，只用于“已保存/已加入生词本/已记下这一招”。

## 2. 降低抗拒的具体机制清单

每条都写了“规则 → 落点 → 怎么验收”。B2/D1 按此逐条验收。

### 2.1 开始成本：打开即继续，无选择

| # | 机制 | 规则 | 落点 | 验收 |
|---|---|---|---|---|
| R1 | 打开即继续 | 有未完成任务时冷启动/回前台直接进做题页原位置（滚动位置、当前题、已选未提交的选项都恢复）；模考同样恢复，计时照走 | §1.1 §5.4 | 从点图标到能读题 ≤ 2 秒（本地数据），0 次点击 |
| R2 | 今天只有一个按钮 | “今天”页主按钮“开始今天的活（约 5 分钟）”；20 分钟/紧急项目收进一行折叠链接“今天时间多？”，默认不展开 | §5.1 | 首屏可点控件中主按钮唯一突出；首屏无时长选择器 |
| R3 | 不用决定学什么 | 内容全部由 C2 按 ROI 生成；用户看不到“选 Part/选考点”的入口（次级入口在复习页底部） | §5.2 | 今天页、结算页无内容选择控件 |
| R4 | 通知/快捷方式直达 | 每日提醒、PWA 快捷方式“继续”点开即进做题页（无未完成任务时直接开始新任务的第一题） | §17 | 点通知到读题 0 次额外点击 |
| R5 | 第一题最顺手 | 每次任务第 1 题选用户掌握度较高、预测正确率 ≥ 85% 的题（热身），不放 P7 长篇 | §5.2 | 埋点：首题正确率 ≥ 85% |
| R6 | 不先上课 | 不出现开课讲解、语法单元、背词单元；讲解只在做错时出现（60 秒小讲解，§8.4） | §8 | 任务内无前置讲解页 |

### 2.2 中断：任何时刻可退且不丢

| # | 机制 | 规则 |
|---|---|---|
| R7 | 每次交互即落盘 | 选中选项、提交、切换文章/题目、滚动位置（停止滚动 500ms 后）、划依据、查词，全部写入本地事件日志（§20）；断电/杀进程最多丢最后 0.5 秒 |
| R8 | 任何形式的离开 = 暂停 | ✕、后退、切 App、锁屏、关浏览器、来电；训练用时环停止；**不弹确认** |
| R9 | 半篇也算数 | P6/P7 做到一半退出，已答的题照常计分与排复习；回来从该篇当前题继续，不要求从头读 |
| R10 | 任务保留到次日凌晨 4 点 | 过期后已答的照算，未答回题池，不出现“过期/未完成”字样 |
| R11 | 退出也算打卡的条件 | 任务中途退出且已答 ≥ 5 题，当天即算打卡（Q3） |
| R12 | 结算也可跳过 | 结算页任何时刻可关；结算数据在“进度”里可补看 |

### 2.3 反馈：每次 10 秒结算，正向、具体

| # | 机制 | 规则 |
|---|---|---|
| R13 | 10 秒结算 | 结算 ≤ 4 行正文 + 1 行同事点评 + 1 个按钮；默认阅读时长按 10 秒设计（≤ 60 个汉字的正文） |
| R14 | 必须具体 | 每次结算至少 1 条**具体的**正向事实，从高到低优先：①某考点掌握度上升（“介词 vs 连词：又稳了一点”）②某类题变快（“审稿 19 秒/句，比目标快 6 秒”）③离目标考点数减少（“还差 14 个考点，−1”）④新收的改写对/生词⑤本周学习天数。禁止空泛夸奖（“你真棒”） |
| R15 | 诚实 | 一题都没进步时只说事实与安排：“碰到 3 个新考点，已经记下，明天换更顺手的题”；不编造进步 |
| R16 | 不显示做题数与对错比 | 结算、进度、周报都不显示“做了 N 题/对 6 题/正确率 71%”，改为考点与用时的变化（Qing：进度不显示做题数） |
| R17 | 快对不打断 | 快对一行反馈，0.8 秒自动下一题（Q6，可关） |

### 2.4 不惩罚

| # | 机制 | 规则 |
|---|---|---|
| R18 | 视觉不惩罚 | 全 App 不使用红色表达错误；错 = 橙色小图标 + “正确答案 C”，不出现大叉、抖动、错误音效 |
| R19 | 不排名 | 无排行榜、无“超过 x% 用户”、无好友 PK、无分享 |
| R20 | 不计负数 | 预测分下降不显示红色负数；日内变化 < 5 分不显示箭头；做题中途不显示预测分 |
| R21 | 断签不清零的部分 | 累计学习天数、考点掌握、预测分永不因断签清零；断签回来只说“欢迎回来”，首个任务降一档 |
| R22 | 不催 | 每天最多 1 条提醒，文案不施压；不出现“你已落后/逾期/还有 N 项未完成”；角标最多“20+” |
| R23 | 查词不扣分 | 查词只让该题多复习一次，第一次查词时说明一次 |
| R24 | 剧情不惩罚 | 同事和主管从不批评；做错时剧情不出现（或只出现中性的“Ken：收到，我再核一下”），不把错题写成“搞砸了工作” |

### 2.5 难度自适应：保持约 75–85% 正确率

- **控制目标**：训练（每日任务、复习、专项）滚动最近 12 次计分作答的正确率保持在 **75–85%**，中心 80%。诊断与紧急项目不受控（要测真实水平）。
- **两层选择**：C2 先按 ROI 选考点（学什么）；同考点内按题目难度估计与用户能力，挑预测正确率最接近 0.8 的题（练哪道）。
- **调节**：窗口正确率 > 85% → 下一题提高一档难度或换到下一个 ROI 考点；< 75% → 降一档、插入一道已掌握考点的“回稳题”，并缩短该次任务的 P7 篇幅。连续错 2 题时下一题必为回稳题。
- **边界**：只在用户目标档的考点范围内调；超出档位的难题不会因为“做得太好”被推上来——做得太好时系统缩短任务、提示“今天的量够了”，而不是加难度轰炸（§5.3）。
- 用户感知：不显示“难度等级”；只在结算偶尔出现“最近做得顺，系统给你换了稍难一点的”。

### 2.6 注意力与时长

| # | 机制 | 规则 |
|---|---|---|
| R25 | 按时间而不是题数结束 | 5 分钟到点做完当前题（P6/P7 做完当前这篇）即结算，不硬切 |
| R26 | 用时环灰色 | 超时只变灰并显示“+8s”，不变红、不闪、不响；可切换“只显示数字/隐藏”（Q6） |
| R27 | 字号就地可调 | 做题页“⋯ → A- A+”即时生效、全局保存；默认 17px |
| R28 | 可预期的长度 | 主按钮写“约 5 分钟”；P7 篇开始前题目视图顶部写“这篇 3 题，约 3 分钟” |
| R29 | 不额外占时间 | 剧情、结算、动画合计 ≤ 任务时长的 5%；剧情不占独立屏 |

## 3. 沉浸感：“你在公司的一天”

### 3.1 一句话

每日任务是“你在 Halvorsen 公司上班的一天”：上午先处理收件箱（P7）、帮同事审几句话（P5）、改一段稿（P6）；每周有一次“紧急项目”（模考），每周一主管给你“绩效评估”（周报）。**剧情跟着题目走，不是题目跟着剧情走**：C2 先按 ROI 选好题，剧情层再给这些题套上场景和一行过渡。剧情永远不影响选题、顺序和用时。

### 3.2 世界观与固定角色（连续出现，人设不变）

公司：**Halvorsen**（沿用第一版原型），一家做贸易与物流的中型公司，有办公室、仓库、客户活动——正好覆盖托业高频场景（邮件往来、订货发货、会议日程、招聘人事、活动通知、出差）。

| 角色 | 身份 | 在任务里干什么 | 说话风格（剧情 1 行） |
|---|---|---|---|
| 你 | 运营部同事（职级随预测分升，§0.5） | 处理文件、审稿改稿 | — （用户不被写台词） |
| Dana Ortiz | 运营部主管，你的直属领导 | 结算点评、绩效评估、发起紧急项目、“主管带你练” | 简短、肯定、具体 |
| Ken Mori | 同组同事，写得快但常手滑 | 发句子给你审（P5） | 随和：“帮我看下这几句～” |
| Mia Park | 市场部，负责活动和宣传稿 | 发段落草稿给你改（P6） | 客气：“麻烦帮我顺一下这段” |

- 头像只用**姓名首字母圆点**（24px，灰底深字），不用插画、不用表情包、不做动画。

### 3.3 一天的结构（真实的一天 = 公司的一天）

| 真实动作 | 公司里的时间 | 说明 |

### 3.4 本周项目线（轻剧情，跨任务连续）

- 每周一个“本周项目”，只决定过渡语和结算点评的话题，例如：客户答谢会筹备 / 新仓库启用 / 季度预算 / 招聘季 / 办公室搬迁 / 海外出差。
- 选择规则：周一按 C2 本周计划中最常出现的场景词包（图谱 `VO.SCENE.*`）选最接近的项目；没有明显主题时用“日常运营”。**项目线不会为了剧情而改变题目。**
- 连续性只靠三件事：①同事名字固定；②过渡语引用上一次任务（“Ken：昨天那几句改得好，今天还有三句”）；③周一绩效评估回顾本周项目（“答谢会的文件都是你经手的”）。
- 不做分支剧情、不做选择对话、不做收集要素。

### 3.5 剧情过渡（≤ 1 行，可关，不拖时间）

- **形式**：下一组题顶部的一行灰色小字（≤ 24 个汉字，13px），和题目同屏出现，**不占独立屏、不需要点击、不阻塞作答**。
- **时机**：只在“场景切换”时出现（例如收件箱 → 审稿），一次 5 分钟任务最多 3 行。同一场景内连续的题不重复出现。
- **示例**：
  - “上午 · Leo 转来两封客户邮件。”
  - “Ken 在群里 @你：帮我看下这三句～”
  - “Mia：答谢会通知的草稿，麻烦顺一下第二段。”
  - “Dana：这份报价单客户在等，看一下。”
- **结算点评**（1 行，§5.3）由 Dana 或刚才发活的同事说，内容必须对应本次的具体事实（R14），例如“Ken：三句都改对了，省了我不少事。”
- **关闭**：做题页“⋯ → 剧情过渡：开/关”与“我的 → 剧情”。关闭后：不显示过渡语和人名，结算点评改为中性的一行事实；**文本样式（邮件信头、聊天气泡、表格）保留**，因为它们本身就是托业文本类型，帮助阅读。
- 默认：开。若用户 3 次以内主动关闭，不再提示重新打开；系统不因关闭而降低任何学习功能。

外壳 = 顶部 1 行场景标题 + 文本容器样式。容器样式只改“边框和信头”，**正文排版（字体、字号、行高、行长）与非沉浸模式完全一致**。

### 3.7 视觉规则：沉浸但不干扰阅读

1. **阅读区零装饰**：文章正文区域内不放图片、插画、背景纹理、头像、动画、emoji（原文自带的除外）。
2. **外壳只在边缘**：场景标题、过渡语、发件人信息都在正文列之外或之上，且合计 ≤ 2 行（≤ 56px 高，手机上折叠成 1 行）。
3. **颜色**：外壳只用 2 个中性灰 + 1 个强调色（品牌蓝，用于当前空/当前题）；黄色只用于“依据/引用高亮”；绿色只用于“✓ 对”；不用红色。
4. **排版统一**：所有文本类型共用同一套正文字号、行高 1.6、最大行长 70 字符；信头/元信息用小一号（–2px）灰字。
5. **动效**：只有切换（≤150ms 淡入）与高亮渐隐（2 秒）；“减少动画”开启时全部关闭。
6. **深色模式**：信头块、气泡、表格边框都有深色版本，对比度同样 ≥ 4.5:1。
7. **简洁外壳**（我的 → 剧情 → 外壳样式：沉浸 / 简洁）：简洁 = 关闭过渡语与人名 + 批注卡改为普通选项列表；文本类型容器仍保留。
8. **验收**：同一题在沉浸/简洁两种外壳下，正文区域像素位置（左边距、行长、行高）一致；D1 截图对比。

## 4. 首日：入职第一天

### S0 欢迎

- 主按钮：开始（约 10 分钟）。链接：我有进度码 → 导入（§17.5）。

### S1 目标分 + 考试日期（Q1）
- 总分按钮 500/600/700/800/900 + 其他，**默认选中 600**。
- 听力估分（可不填）：“不确定”默认选中 / “约 ___ 分”。
- 实时显示：“你的阅读目标：约 270 分”（填听力 → 总分−听力，下限 5、上限 495，取 5 的倍数；不确定 → 总分×0.45 取 5 的倍数）。旁边“改一下”可手调阅读目标。
- 考试日期：日期选择 / “还没定”。天数提示分三档：>60 天“时间充裕，每天 5 分钟够用”；15–60 天“每天 5–20 分钟比较稳”；<15 天“进入冲刺，只练最能提分的部分”。
- 校验：日期早于今天 → 行内“这个日期已经过了，换一个吧”。

### S2–S3 入职词汇摸底（Q4，约 3 分钟）
- 说明屏 4 行：认识点“认识”，不确定点“不认识”；有几个编出来的假词；偶尔让你选一下意思；3 分钟自动结束。
- 做题：单词大字 28px 居中；底部两个等大按钮“不认识 / 认识”（PC：← / →）。约 40 真词 + 6–8 假词 + 5–6 次四选一抽查（只抽点了“认识”的词，含“不知道”选项）。
- 不显示对错、不显示进度分数；顶部只显示“约 2:10”。3 分钟到点自动结束；✕ 暂停，暂停菜单“结束测试”（已答 ≥ 20 个即可出结果）。
- 结果 1 屏：“你大约认识 3,200 个常用词，商务词认识约 45%。文章里的生词会控制在你读得顺的范围。”
- 跳过 → 按 3,000 词先验；今天页顶部出一条可关提示“补测词汇（3 分钟），推荐会更准”。

### S4–S5 入职测试（约 12 题，约 5 分钟）
- 组成沿用 v1（P5 6 题难度 2→4 + P6 一篇 4 题 + P7 单篇 ≤ 3 题），按词汇结果调起始难度；目标 ≤ 250 时 P7 选通知/短信等短文本。
- 无反馈、无查词、无“稍后再做”、不显示用时；每题下方小字“不会就选一个，继续下一题”。单题超过目标用时 2 倍 → 温和提示同句。
- 中途退出保存，下次从下一题继续。

### S6 结果 + 你的考场作战卡（诊断完成 = 第 1 天打卡）
- 预测阅读分区间（“245（195–295）”）+“离目标还差 **16 个考点**，约 **7 小时**”（§11.2）。
- “你拿得稳的：词性判断、找细节”；“最快涨分的 3 个：介词 vs 连词 / 同义替换 / 主旨题”。
- 作战卡（本档 ≤ 8 条，个人化数字，§6.1）。底部固定一句：“没做完是计划内的，不是失败。”
- 计划一行：“每天 5 分钟，约 X 周到目标”（估不出不写周数）。
- 主按钮：“明天见”（今天已打卡）；次按钮：“现在再做 5 分钟（可选）”。首日 5 分钟任务不放复习，全是前 2 个薄弱考点 + 1 篇 P7 短文。
- 一次性询问提醒：“要不要每天提醒你？[早上 7:30] [晚上 20:30] [不用]”。
- 跳过测试的用户：S6 写“先按词汇量估：约 220–300 分，练 2–3 天后更准”；作战卡用档位默认值。

```

· 介词 vs 连词：又稳了一点
· 审稿 19 秒/句（目标 25）
· 离目标还差 14 个考点（−1），约 6 小时
预测阅读分 265（240–290）

```
- 正文 ≤ 4 行，按 R14 优先级挑 2–3 条具体事实；没有进步时按 R15。
- 预测分变化 < 5 分写“持平”；下降写“这次难题多，别在意单次”，不写红色负数（R20）。
- 晋升职级：顶部多 1 行“Dana：下周起你是资深专员了。”（静态，无动画）。
- 个性化建议（§18）最多每 2 周在结算出现 1 次，位于点评下方 1 行，可点“不用”。
- “看错题解析”链接：只在本次有错题时出现。
- 结算页 15 秒无操作不自动关闭（老年用户可能慢读），但任何时候可关（R12）。

### 5.4 断点续做

- 每次交互落盘（R7）：当前题、选中未提交的选项、已用时间、P6/P7 读到第几篇、**文章与题目视图各自的滚动位置**、多篇当前标签、划的依据、打开的查词浮层（关闭即可，不恢复浮层）。

## 6. 技巧：对用户只分三类

数据源：`data/strategies/strategies_v2.json`（93 条；`delivery`=user 85 / engine 8；`min_sets` 各档最小技巧集）。用户永远看不到“技巧库”“93 条”这类概念，只遇到下面三种形态。

| 类 | 用户看到什么 | 数量上限 | 来源与规则 |
|---|---|---|---|
| ① 考场作战卡 | 一张卡，考场上要照做的行动句，带个人数字 | **每个目标档 ≤ 8 条** | 该档 `min_set` 中属于“考场时间/顺序/放弃/涂卡”的条目（策略节点 `ST.TIME.* / ST.ORDER.* / ST.GIVEUP.* / ST.BUBBLE.*`），按 roi 升序、档专属优先，合并同义后取前 8 |
| ② 系统自动执行 | 无感（最多在结算里一句“系统已经替你……”） | 不限 | 全部 `delivery=engine` 条目 + 能由界面/排程直接执行的 user 条目（见 §6.2） |
| ③ 记一招 | 做错题后，解析里最多 1 条可收藏的技巧 | **每次错题 ≤ 1 条**；每次任务 ≤ 3 条 | 其余 user 条目，按错题考点（`graph_nodes`）与错因匹配，只取用户档位适用（`bands`）的 |

不在任何一类里出现的：roi=3 且不在任何档 min_set 的条目（如“做完的题听一遍音频”“找更难的 P7 练”），只在“进度 → 作战卡 → 全部规则（可选看）”里按档折叠展示，默认不推送。

### 6.3 记一招（错题时每次 ≤ 1 条）

- **触发**：训练中答错（或慢对且超时 ≥ 1.5 倍）后，解析第 4 段“记一招”从匹配池取 1 条；没有匹配的就不出（宁缺毋滥）。
- **匹配**：错题的考点/题型节点 ∩ 技巧 `graph_nodes`，且技巧 `bands` 包含用户档位；多条命中时按 roi 小者、用户未收藏过者优先；同一条 7 天内最多出现 2 次。
- **形态**：一行 `plain_zh`（如“看空格后面：跟名词用介词，跟完整句子用连词”）+ 右侧“记下 ☆”。点“记下”→ 进入“复习 → 我记下的招”，并以四选一情景题形式进入复习队列（“这句该先看哪里？”），自动评分。
- **不记也没关系**：不点就不进复习，不提示第二次确认。
- 详细说明（`detail_zh`）折叠在“为什么 ›”里。
- 诊断、紧急项目中不出现（交卷后的报告里可看）。

## 7. 做题页：三端布局细节

### 7.1 通用结构

- 顶部栏（高 48px）：✕ ｜ 场景标题 + 小字 Part ｜ 进度点 ｜ 用时环 ｜ ⋯。
- 剧情过渡行（可选，§3.5）：顶部栏下方 1 行，进入新场景时出现，滚动时随内容上移。
- 选项：整行可点，≥ 48px 高，间距 ≥ 8px；**选中即提交**（训练默认），“我的”可改“选中后确认”。
- 工具（训练可用，诊断/紧急项目不可用）：点词即查（§7.6）、划依据（长按/双击句子 → 黄底）、稍后再做（⋯ 菜单里，不显眼）。

### 7.2 Part 5 审稿（文档批注样式）

- 手机：上方“文档行”放句子（空格为下划线框），下方批注卡“Ken：这里用哪个？”+ 四个选项；选项区固定在屏幕下 1/3（拇指区）。句子很长时句子区可滚动，选项区不动。
- 平板/PC：不分栏；句子与批注卡居中，最大宽 720px；PC 批注卡在句子右侧（≥ 1180px）或下方。
- 键盘：1–4 / A–D 选择，Enter 下一题。

### 7.3 Part 6 改稿（文档 + 修订标记）

- 手机：文档在上，选项在底部抽屉（默认 40% 屏高，可上拉 75%、下拉到 1 行“第 132 空 · 展开”）。点文档里任一空 = 跳到该题；答完自动跳下一个空，并把文档滚到该空位于屏幕上 1/3。
- 平板/PC：左文右题（同 §7.5 分栏）；右栏 4 个空的题卡纵列，当前题展开、其余折叠为 1 行“131 ✓ has finished”。
- 插入句题：文档中 [1]–[4] 位置显示为细竖线标记；对 600 档以下（作战卡“插入句直接涂”），训练中不出插入句题。

### 7.4 Part 7 收件箱 · 手机单栏：文章/题目切换

- **顶部分段按钮** [文章 | 题目 2/3] + **右下浮动切换钮**（56px，拇指区；左手模式镜像到左下）。两者等价。题目视图底部另有“看文章”大按钮。
- **默认先显示题目视图**（系统执行 S2-P7-01）；前 3 篇顶部提示一次“先看题，再去文章里找”。题目视图顶部写“这篇 3 题，约 3 分钟”（R28）。
- **保留滚动位置**：文章视图与题目视图各自记住滚动位置；多篇时每篇各自记住；切换不重置、不跳顶。切换动画 ≤ 150ms 淡入，可关。
- **题目引用句高亮回原文**：
  - 题目本身引用了原文位置时（“In paragraph 2, line 3, the word ‘cover’…”、“the phrase ‘out of service’”、插入句的 [1]–[4]、“according to the e-mail”），题干里的引用部分显示为可点小块“第 2 段 ‘cover’ ↗”。
  - 点击 → 切到文章视图（多篇时自动切到对应标签），把该句滚到屏幕上 1/3，黄色高亮 2 秒后渐隐为浅下划线（保留到本篇结束），同时底部出现“↩ 回到题目”胶囊。
  - **答题前只定位题目自己点明的位置，绝不提示答案依据**；答题后（反馈阶段）才出现“依据在 邮件 第 2 段 ↗”，点击同样跳转高亮。
  - 无法定位（原文无段落/行号数据）时，引用块显示为普通文字，不可点。
- **多篇子切换**：文章视图顶部二级标签 [邮件][网页][表格]，标签写文本类型；当前题涉及的篇在标签上加小圆点（只依据题干明文提到的篇名，答前不暗示跨篇关系）。
- 表格在窄屏只允许表格区域横滚；其他内容永不横滚。

### 7.5 Part 7 · 平板横屏 / PC：左文右题，可拖分隔

- **分栏**：左文 55% / 右题 45%（默认）；中缝 8px 可拖动，范围 40–70%；双击中缝恢复默认；键盘 Alt+← / Alt+→ 每次 5%。比例按设备记住。右栏最小 320px，左栏正文最大行长 70 字符（多余留白）。
- **多篇组标签页**：左栏顶部标签 [邮件 1/3][网页 2/3][表格 3/3]，`[` `]` 切换；每篇独立滚动位置。≥ 1440px 时 ⋯ 菜单可选“并排看两篇”（左栏再一分为二，仅双/三篇可用，默认关）。
- **右栏**：顶部题号点“1 ✓ 2 ● 3 ○”，点击跳题；当前题与选项；反馈在当前题下方展开，不遮文章。
- **引用跳转**：同 §7.4，但不切视图——左栏直接滚动并高亮，右栏保持不动。
- 平板竖屏（600–899px）：默认同手机切换；可在设置改“上下分屏”（上文 55% / 下题 45%，中缝可拖）。

### 7.6 点词即查：浮层不遮挡题目

- 触发：手机单击英文词；PC 单击或双击（设置可选），不响应悬停。词形自动还原（offered→offer）。
- **手机**：底部弹层，高度 ≤ 35% 屏高；
  - 在文章视图点词 → 弹层在底部，文章自动上移使被点词位于弹层上方；
  - 在题目视图点题干或选项里的词 → **弹层从顶部下拉**（选项在下方拇指区，不能被盖住）；
  - 下滑或点空白关闭。
- **平板/PC**：词旁气泡（宽 ≤ 320px），**只在被点词所在的栏内定位**，碰到栏边自动翻转，永不越过中缝盖到题目栏；Esc 关闭。
- 内容：词 + 音标 + 词性 + TOEIC 语境释义（LEE-WHITE，繁转简）→ ECDICT 兜底；例句 1 句；“★ 托业高频”；“已加入生词本 [移除]”。查不到：“这个词词典里没有，多半是人名/地名，可以跳过”。
- 自动入生词本，不弹确认；第一次查词时弹层底部出现一次“查词不扣分，查过词的题会多复习一次”。
- 诊断/紧急项目中点词无反应，第一次 toast“模考中不能查词，交卷后可以查”。
- 渐隐注释（P1）：超出用户词汇量且不在目标词表的词以虚下划线标出，点一次后不再标。

### 7.8 用时显示

## 8. 答后反馈、记一招、60 秒小讲解、改写对

### 8.1 反馈层级（训练）

| 情况 | 默认展示 | 折叠 |
|---|---|---|
| 快对（≤ 目标用时、未查词） | 一行“✓ 对 · 14 秒（目标 25）”，**0.8 秒后自动下一题**（可关） | 解析 |
| 慢对 | “✓ 对 · 41 秒（目标 25）· 方法对了，下次可以更快” + 一句提速招（来自记一招池，计入每次 ≤1） | 完整解析 |
| 错 | “正确答案 (C)”（橙色小图标，无大叉）+ 解析自动展开 | — |
| 查过词 | 加小字“查了 2 个词，这题明天再见一次” | — |

- 慢对/错需点“下一题”（拇指区）。剧情在错题时不出现（R24）。

### 8.2 中文解析（固定 4 段，每段 ≤ 2 行）

依据（原文黄色高亮，P7 带“依据在 邮件 第 2 段 ↗”跳转）→ 为什么（大白话）→ 你选的错在哪（干扰项套路）→ 记一招（≤ 1 条，可“记下 ☆”）。底部一行“考点：时态与时间状语”，**不显示掌握百分比**（百分比只在进度页的考点详情里）。

- 只有英文解析的题：显示英文解析 + 小字“中文解析制作中”。
- 禁止术语单独出现，必须带白话。

### 8.3 改写对卡（同义替换）

- P7（及部分 P6）答完后，若题目有“原文 ↔ 选项”改写对，在解析下方出一张卡：“原文 out of service ↔ 选项 temporary closure · 托业爱这样换说法”；[不用记] [记住了]。做对的题也出；每次任务最多 2 张。
- 剧情包装：卡片标题“Leo 的备忘：这两个说法是一回事”（剧情关闭时为“改写对”）。

### 8.4 60 秒小讲解（语法不前置的承接）

- **触发**：答错一道语法类题（图谱 `GR.*` 叶考点），且该考点不在用户档位的“专门练”范围（600 档：除词性 `GR.POS`、介词与连词 `GR.CONN` 以外的语法）；或同一档内考点连错 2 次。
- **形态**：解析下方一个按钮“看 60 秒小讲解（Dana 带你看）”，**不自动打开**。打开后 1 屏：一条规则（≤ 2 行大白话）+ 2 个对比例句（对/错）+ 1 道立即验证小题（自动评分，不计入考点掌握，只用于确认看懂）。顶部有 60 秒进度细条，读完可随时关。
- 同一考点 7 天内只推 1 次；看过后该考点的错题照常进复习。
- 不出现“语法课程”“章节”“第几讲”等形式。

## 9. 语法不前置（规则汇总）

| 档 | 专门练（进每日任务新题） | 只在做错时给 60 秒小讲解 |
|---|---|---|
| 入门 / 600 档 | 词性判断（GR.POS）、介词与连词（GR.CONN）——依据 S2-P5-03 | 动词形态、代词、非谓语、关系词、比较、特殊句式等全部其余语法 |
| 730 档 | 上述 + 动词形态（GR.VERB）、代词（GR.PRON）、非谓语（GR.NONFIN）、关系词（GR.REL），按 ROI 逐步加入 | 比较、特殊句式 |
| 800+ 档 | 全部 `GR.*`，按 ROI | — |

- 任何档都**不安排开课式讲解**；“主管带你练”（专项）的流程里只在第 ② 步放一张 60 秒讲解卡（§10.3）。
- P6 段落、诊断、紧急项目里自然出现的其他语法题照常计分，错了走 §8.4。

## 10. 复习

### 10.1 复习页

- 顶部卡：“今天该复习 12 个，约 4 分钟”+ 主按钮“开始复习”；小字“这些也会自动放进今天的活里，不单独做也行”。
- 分类计数只显示**今天到期的**（错题 5 · 生词 5 · 改写对 2），不显示累计总数。
- “主管带你练”：最该补的 3 个考点（按 ROI），每行“介词 vs 连词 · 约 6 分钟 [开始]”，**不显示掌握百分比**（避免低分羞耻），点进详情才看。
- 列表入口：待办复查（错题）/ 生词本 / 改写对 / 我记下的招 / 自己挑着练（按 Part，标“可选”）。

### 10.2 复习机制（给 C1 的 UX 约束，沿用 v1）

- 自动评分：错/查词/看了解析再答 = Again；对但超时 = Hard；对且 ≤ 目标 = Good；对且 ≤ 0.6×目标且该卡已复习 ≥ 1 次 = Easy。
- 题卡复习默认换同考点新题，原题隔天再出；无新题时出原题并打乱选项。
- 生词复习：英文词 → 四选一中文义（干扰项同词性同主题），对且 ≤ 4 秒 = Good。
- 记下的招：情景四选一（“遇到这种句子先看哪里？”），自动评分。
- 新题快对且未查词不建卡；复习一次最多 20 个，积压按“考频×遗忘程度”排序，其余平摊（§14.3）。
- 剧情包装：复习段标题“回头看看上周的文件”（剧情关闭时为“复习”）。

### 10.3 主管带你练（专项）

① 补底 2 题（前置考点）→ ② 60 秒讲解卡（1 条规则 + 2 个例句）→ ③ 阶梯 5–8 题（连对 3 题提前过关）→ ④ 过关页：“介词 vs 连词：稳了。7 天后 Dana 会再抽查 2 题。”
- 只列与目标档相关的考点；超出档位的折叠在“以后再说的”，写明“这个考点对 600 档性价比低”。

### 10.4 待办复查（错题本）

- 按 Part/考点筛选；每条：题干前 40 字、错因标签（系统自动推断）、下次复习“明天/3 天后”。
- 不显示“累计错 N 次”，只显示“已复习 2 次，越来越稳”。

### 11.1 进度页结构（自上而下）

```
────────────

────────────

────────────

```
- **不显示做题数、正确率、学习时长排行**（R16）。累计学习天数保留（努力不清零）。

### 11.2 “还差 N 个考点，约 X 小时”的口径（给 C2/C3）

- **考点池**：图谱中 `target_band ≤ 用户目标段` 的非汇总节点（`data/graph_v1_summary.md` §4 的攻克顺序），排除技巧层与文本类型层的“影响面估计”节点中不可直接训练的。
- **N**：按 ROI（exam_weight × 预计提分 ÷ 预计分钟）从高到低累加尚未达到“稳”（掌握度 ≥ 0.8，且最近一次复习正确）的考点，直到这些考点全部达稳时**预测分中值 ≥ 目标**；N = 累加的考点数。即：N 是“够达标的最少考点数”，不是“全部没学的考点”。
- **X 小时**：N 个考点的预计学习分钟之和（个人学习速度，先验来自同档用户；含它们带来的复习）÷ 60，四舍五入到 0.5 小时；< 1 小时写“不到 1 小时”。
- **换算一行**：按用户最近 14 天平均每日有效分钟换算成“约 N 周”；无历史时按每天 5 分钟。
- 预测分已 ≥ 目标且区间下沿 ≥ 目标 − 10：显示“已经够到目标了 ✓ 现在只需每天复习保持”，并在周报问是否提高目标（§15.3）。
- 区间宽 > 120 分时：N 与 X 不显示，写“估算中，再练 2–3 次就能算出来”。
- N 变化在结算显示（“−1”）；N 上升（如改高目标、长期未学导致遗忘）时只在进度页静默更新，不在结算里写“+N”。

### 11.3 考点详情

- “正在攻”：每个考点一行，进度条（掌握度）+ “约 20 分钟可稳”；“已稳”：灰色列表，带“下次抽查：5 天后”。
- 这里是唯一显示掌握百分比的地方，用条形而非数字为主。
- 能力地图（图谱）默认折叠，只列与目标相关的前 20 项，不出现节点 ID。

### 11.4 预测分展示规则（给 C3，沿用 v1 并收紧）

- 永远显示区间；区间宽 > 120 分只写“估算中”。
- 达标把握：<30%“还需要一段时间”；30–70%“有希望，继续”；>70%“很稳了”。
- 今天页显示当日开始时的数；做题中途不显示；结算才显示变化。
- “这个分怎么算的？”→ 大白话一段。

## 12. 紧急项目（全真模考）

- **入口**：倒排阶段到期时在今天页条件卡出现“Dana：下周有个紧急项目，找一段不被打扰的 75 分钟”；也可从今天页“今天时间多？”进入。
- **说明屏**：75 分钟 · 100 题 · 和真考一样；中途不能查词、没有解析；可以暂停但时间照走；作战卡（本档 ≤ 8 条）显示在此；[开始] [以后再说]。
- **做题页**：最简外壳（§3.6），无反馈/查词/稍后再做；划依据保留。题号网格（手机点“32/100 ▾”展开 10×10；PC 右栏常驻）；**终点线**画在档位终点题号后，到达时提示一次“到终点线了：剩余时间挑一篇就能答的题做，或现在统一涂 B”；“把所有空着的涂成 [B▾]”一键完成。
- **交卷确认**：“还有 12 题没做，交卷后按错算。要不要先统一涂 B？[涂上再交] [直接交卷] [回去做]”。
- **报告**：阅读分（区间）· 是否达到目标 · 分 Part 拿分率 vs 作战卡计划（“P5 70%，计划 2/3 ✓”）· 用时 vs 计划（超出写灰色“+6 分”）· 作战卡执行（终点线 ✓ 涂满 ✓）· 丢分最多的 2 个考点（已自动加进今天的活）· Dana 一句点评。报告用拿分率而不是题数。
- 整套都做过：“可以重做（分数仅供参考）”。

## 14. 断签保护与不惩罚

### 14.1 规则（Q3）

- 打卡：当天完成一次任意时长任务（5 分钟按时间到或答 ≥ 5 题；首日诊断完成也算）。一天界限：本地凌晨 4 点。
- 断签保护卡 ❄：连续学 3 天得 1 张，每天最多得 1 张，最多存 2 张；断签自动消耗。首次获得时说明 1 次。
- 主强调“本周学了几天”（目标每周 4 天），连续天数次要；周出勤 ≥ 4 天在绩效评估写“出勤 ✓”。

### 14.2 断签后回来

- 一屏：“欢迎回来。休假回来，先处理几件简单的。”+ 主按钮“开始（约 5 分钟）”。
- 不显示“连续天数已归零”“错过 X 天”；累计天数保留。
- 回来后第一个任务降一档（掌握度高的考点 + 少量复习）。

### 14.3 复习积压

- 每日任务里复习 ≤ 一半；复习页“今天该复习”最多 20，其余“会分到接下来几天”。
- 积压超 3 天量：C1 按“考频×遗忘程度”挑最值得的，其余平摊到后续 5–7 天。
- 不出现“逾期”、红色数字角标；角标最多“20+”。

### 15.1 档位定义（沿用 v1，C2 可校准）

| 档位 | 阅读目标 | 认真做（正确率 70–80% 时） | 跳题预算 | P7 终点线 | P5+P6 用时 |
|---|---|---|---|---|---|

诊断/模考后 C2 用真实正确率 p 按 v1.1 §0 公式（答对 ≈ A×p + (100−A)×0.25）算个人 A，作战卡显示个人数字。

### 15.2 档位怎么影响用户看到的东西

1. 作战卡内容（§6.1）。
2. 每日任务过滤：超出档位的题型/考点不进任务；“自己挑着练”里标“可选 · 超出你的目标”。
3. 语法专门练范围（§9）。
4. 档位内一次性提示（系统执行）：如 600 档 P5 词汇题超过 15 秒未答，题目下方淡出一行“词汇题一眼不会就选一个走”——每条每周最多 2 次，可“不再提示”；**不计入记一招配额**（它不是错题后出现）。
5. 紧急项目终点线。

### 15.3 档位变化

- 改目标 → 立即重算，toast 写清变化。
- 预测分稳定超过目标 30 分（连续 2 次紧急项目）→ 绩效评估里问“已经稳过目标，要不要提高一点？[提到 300] [保持不变]”，不自动改。

## 18. 越用越贴合（用户能感知到的部分）

系统内部持续更新四类画像；规格只规定用户能看到、能关的部分。

| 画像 | 系统在做什么（用户无感） | 用户会看到什么（示例文案） | 出现条件 | 可关吗 |
|---|---|---|---|---|
| 个人记忆参数（FSRS 个人化） | 用本人作答数据拟合遗忘速度，调整复习间隔 | “你记单词比一般人稳，生词复习间隔已经拉长，复习会少一点。” | ≥ 300 次复习后；一次性 | 说明可关；参数本身属于核心算法不可关，可“重置个性化” |
| 考点掌握度 | 每题后更新，驱动 N 个考点与 ROI | 进度页“还差 N 个考点”；结算“介词 vs 连词：又稳了一点” | 始终 | 不可关（核心） |
| 各 Part 用时画像 | 个人目标用时与 P7 篇幅控制 | “你读邮件比读新闻快不少，新闻类题多给了你 10 秒。” / “审稿已经达到考场速度，今天起少排一点。” | 某类与同档基线差 ≥ 20%，且样本 ≥ 30 题 | 可关（关后目标用时回到档位默认） |
| 作息画像 | 统计不同时段的正确率与完成率 | “系统发现你晚上 9 点后正确率低一些，建议早上做。[把提醒改到 7:30] [不用]” | ≥ 14 个学习日、两时段差 ≥ 10 个百分点且置信区间不重叠；每 2 周最多 1 次 | 可关（“作息建议”开关） |

- **出现位置**：结算点评下方 1 行或绩效评估底部 1 条；同一时间最多 1 条；“不用”= 该类 30 天不再提；“不再提示此类”= 永久关。
- **语气**：只说观察和建议，不评价（不说“你晚上状态差”）；建议总是带一键执行和“不用”。
- **我的 → 越用越贴合**页：列出上表四项的当前一句话说明（如“复习间隔：已按你的记忆速度调整”）、两个开关（各 Part 用时自适应、作息建议）、“系统调整说明”开关（关 = 不再出现上表的提示句，后台仍在优化）、“重置个性化”（二次确认，回到先验参数，不删作答记录）。
- 隐私说明一句：“这些都只在你的设备上计算。”（同步上线后改为“随你的进度一起同步”。）

## 19. 每个页面的状态：首次 / 空 / 加载 / 离线 / 出错

总原则：
- **加载**：数据都在本地，常规页面 < 300ms 不显示加载态；超过 300ms 显示骨架屏（灰色块，形状同最终布局，无转圈），超过 3 秒加一行“正在准备…”。不使用全屏转圈。
- **离线**：首次装好内容包（题库 + 离线词典）后，全部学习功能离线可用，**离线不提示**；只在需要网络的动作（云同步、检查更新、首次下载）上说明。
- **出错**：先保住进度，再给一个能继续的动作；文案不说“失败”，说“出了点问题，你的进度已保存”。错误信息可复制，但不展示技术细节。
- **首次**：每个页面首次进入最多 1 条说明（≤ 2 行，可关，关后不再出现）。

| 页面 | 首次 | 空 | 加载 | 离线 | 出错 |
|---|---|---|---|---|---|
| 首次启动 / 内容包下载 | 欢迎屏 S0 | — | “正在准备题库和词典（约 x MB）”进度条；可先做目标设置（不依赖内容包） | 首次且无内容包：“第一次需要联网下载题库，之后断网也能用。”[重试] | 下载中断：自动续传；3 次失败：“网络不稳，连上 Wi‑Fi 后会自动继续”，已下载部分保留 |

## 20. 数据事件日志（沿用 v1 §15，新增事件见 20.4）

### 20.1 原则（为 D3 同步做准备）

- **只记事实，不记派生状态。** 掌握度、FSRS 间隔、预测分、连续天数、断签保护卡都由回放事件**重算**，所以多设备合并时只需按时间合并日志，天然无冲突。
- **追加写，不改不删。** 修改设置也是新事件（后写的覆盖前写的）。
- **每条事件可独立理解**（带足够的上下文字段），即使题库版本变了也能回放。
- 本地上限沿用 2 万条；超出时把最早的事件压缩为“快照事件”`state_snapshot`（含当时派生状态 + 已覆盖的事件范围），不直接丢弃。
- 与现有 v2 log 的映射：`answer`→`answer_submit`，`word`→`word_lookup`，`start/end`→`session_start/session_end`，`later`→`item_defer`，`hl`→`highlight`，`rule`→`rule_card_view`，`wordrev`→`review_answer`（type=word），`profile`→`profile_create`，`export`→`data_export`。B2 迁移时写转换器。

### 20.2 公共字段（每条都有）

| 字段 | 说明 |
|---|---|
| `eid` | 事件 ID（UUID v4 或 ULID，按时间可排序优先 ULID） |
| `e` | 事件名 |
| `t` | 客户端时间戳（UTC 毫秒） |
| `tz` | 本地时区偏移（分钟，如 480），用于算“哪一天” |
| `pid` | 档案 ID（本地生成 UUID；同步后绑定账号） |
| `did` | 设备 ID（首次启动生成） |
| `seq` | 本设备自增序号（检测丢失/重复） |
| `sid` | 会话 ID（一次任务/诊断/模考；无则空） |
| `av` | App 版本 |

## 21. 可访问性（沿用 v1 §14，补充 v1.1 项）

- 对比度：正文 ≥ 4.5:1、大字/图标 ≥ 3:1（WCAG 2.2 AA），浅色/深色、沉浸/简洁外壳都要满足；信头灰字同样 ≥ 4.5:1。
- 不靠颜色：对/错/当前空/终点线/引用高亮都有图标或文字；群聊发言人靠名字区分，不靠颜色。
- 点击区域 ≥ 44×44pt；选项 ≥ 48px；浮动切换钮 56px；中缝拖动热区 ≥ 24px（视觉 8px）。
- 缩放：“超大”字号或系统 200% 时手机单栏不横滚（表格除外），按钮文字换行不截断；PC 分栏在超大字号下若右栏 < 320px 自动改为切换模式。
- 单手：主操作都在下 1/3；左手模式。
- 不施压：计时可隐藏；无音效；无闪烁（< 3 次/秒）；减少动画时关闭所有过渡与高亮渐变（高亮直接出现、直接保留）。
- 读屏：图标按钮中文标签（“退出，进度已保存”“切换到文章”“回到题目”）；选项读“选项 A，finishes”；反馈 aria-live=polite；P6 空位读“第 132 空，未作答”；引用块读“跳到原文第 2 段 cover”；剧情行标记为补充说明（aria-describedby），可被读屏跳过；聊天气泡读“Leo Chen，9:05，……”。
- 键盘：全流程可键盘完成（§7.7），焦点框清晰；浮层打开时焦点进入浮层，Esc 返回原词。
- 认知负担：每屏 ≤ 1 主按钮、≤ 3 个数字；术语禁用表（FSRS、节点、θ、logit、保持率、ROI、bundle、qtype、min/pt）。
- 语言：界面简体中文；英文正文 `lang="en"`。
- 年长用户：默认 17px，不默认大字；系统大字时提示一次。
