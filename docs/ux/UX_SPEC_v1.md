## 0. 设计原则（每一屏都用这 8 条检查）

1. **一屏一件事，一个主按钮。** 主按钮永远在拇指区（手机底部），次要操作做成文字链接。
2. **用户只做一个选择：今天学多久**（默认 5 分钟）。学什么、复习什么、先后顺序全由系统按 ROI 排好。
3. **不让用户自评。** 记忆评分全部自动：快对=Good（很快=Easy）、慢对=Hard、错或查词=Again。界面里不出现“认识/模糊/不认识”“简单/困难”按钮。
4. **够用就好。** 每处都告诉用户“对你的目标分来说，这些就够了”；超出目标的内容标“可选”，不催。
5. **不惩罚。** 断签、做错、查词、跳过都不扣分、不出红色大叉、不出“你已落后”。断签回来只说“欢迎回来”。
6. **大白话 + 对比清晰。** 文案按 35–50 岁、多年没考试的人写：短句、不用术语（不出现 FSRS、节点、θ、logit、保持率）。数字都给对比：“18 秒（目标 25 秒）”“比上周 +15 分”。
7. **游戏外壳只服务分数。** 职场说法（审稿/改稿/收件箱/绩效评估/职级）只做包装，非答题时间 ≤10%；任何动画 ≤1 秒、可关。
8. **离线优先。** 所有学习功能断网可用；同步只是附加。

**决定：主导航 4 个入口，不再把“收件箱/改稿/紧急”做成独立 Tab。** 理由：v1 原型的 5 个职场 Tab 让用户自己选练什么，违背“只选时长”；v2 的“薄弱点/图谱”两个 Tab 对目标用户太技术。外壳保留在任务内（题卡样式、标题、一句反馈），另在“复习 → 自己挑着练”里提供按 Part 自由练的次级入口（见 §19 Q2）。

现有 v2 Tab → v1 规格映射：工作台→今天；薄弱点→复习/薄弱点攻克 + 进度；复习→复习；图谱→进度/能力地图（默认折叠，只列与目标相关的前 20 项）；我的→我的（PK 降级为“以后”）。

## 2. 首日流程

总时长目标：**约 9–10 分钟到达“今日 5 分钟”入口**（目标 0.5 分 + 词汇 3 分 + 诊断 约 5 分 + 结果 0.5 分）。每一步都可以“下次再说”，进度保存；任何一步退出后，下次打开从该步继续，顶部显示“还差 2 步就能开始”。

步骤条（顶部细条，4 段）：目标 → 词汇 → 诊断 → 开始。

└──────────────────────────────┘

- 文案细则：
  - 总分按钮默认选中 600（最常见），不默认空。
  - 阅读目标默认算法：填了听力 → 阅读 = 总分 − 听力（下限 5、上限 495，取 5 的倍数）；“不确定” → 阅读 = 总分 × 0.45（取 5 的倍数；依据 v1.1 §0：入门考生听力通常高于阅读，**不要把阅读目标定太高**）。见 §19 Q1。

  - 天数提示按距离分三档：>60 天“时间充裕，每天 5 分钟够用”；15–60 天“每天 5–20 分钟比较稳”；<15 天“已进入冲刺，我们会只练最能提分的部分”。
- 按钮：下一步 → S2；返回 → S0。
- 校验：日期早于今天 → 行内提示“这个日期已经过了，换一个吧”。

```

### S5 快速诊断（做题）
- 题目组成：沿用 v2（P5 6 题难度 2→4 + P6 一篇 4 题 + P7 单篇 ≤3 题，约 12 题），**按词汇量结果调起始难度**；若用户目标 ≤ 250，P7 选短文本类型（通知/短信）。
- 做题页与 §4 相同，但：无反馈、无查词、无“稍后处理”；顶部写“诊断 5/12”；每题下方有小字“不会就随便选一个，选完就下一题”。
- 单题超过目标用时 2 倍 → 题目下方温和出现“可以先选一个，继续下一题”（不强制）。
- 中途退出 → 保存，下次从下一题继续。

## 3. 每日任务与断点续做

### 3.1 时长档

| 档 | 名字 | 组成（C2 按 ROI 生成；以下为默认配比） | 预计题量 |
|---|---|---|---|
| 5 分钟（默认） | 今日任务 | 到期复习 ≤ 一半 + 薄弱点新题；以 P5 为主，每 3 天至少 1 篇 P7 短文 | 6–10 题 |
| 20 分钟 | 加量 | 复习 ≤ 一半 + P5 ×8 + P6 1 篇 + P7 单篇 1–2 篇（按终点线内的文本类型） | 18–24 题 |
| 75 分钟 | 全真模考 | 整套 100 题，见 §7 | 100 题 |

- **主界面只显示 5 分钟主按钮**；20/75 是链接。用户在“我的”里可把默认改成 20 分钟。
- **按时间而不是题数**：到 5 分钟时，做完当前题（P6/P7 做完当前这篇）即进入结算，不硬切。结算页提供“再来 5 分钟”。
- 题量随用户速度自适应：上次 5 分钟只做了 5 题，这次就排 5–6 题。
- 每日复习上限约一半（PRODUCT_BRIEF）；积压的复习不一次性压给用户（§9.3）。
- 超出终点线的内容（如 600 档的三篇阅读）不进每日任务，只在“自己挑着练”里标“可选：超出你的目标”。

### 3.2 结算页（每次任务后，≤ 10 秒看完）

```
┌──────────────────────────────┐
│ 今日任务完成 ✓   用时 5:20      │
│ 8 题对 6 题 · 平均 21 秒（目标 25）│
│ 预测分 265 → 270  ▲5           │
│ 介词 vs 连词  ▲  掌握 52%→61%    │
│ 新加入复习：2 题 · 生词 3 个     │
│ 主管点评：“这份稿子改得又快又准。” │  ← 职场一句
│ 🔥 连续 5 天                     │
│ [         完成          ]      │
│   再来 5 分钟  ·  看错题解析      │
└──────────────────────────────┘
```
- 预测分变化 < 5 分时写“预测分 265（持平，正常波动）”，**不写负数红字**；下降时写“这次难题多，预测 265→260，别在意单次”。
- 晋升职级时，结算页顶部多一行“晋升：专员 → 主管”（静态徽章，≤1 秒动画）。

### 3.3 断点续做

- **每答一题即落盘**（本地），包括 P6/P7 读到第几篇、划的依据、当前题已用时间。
- 退出方式：✕、切到别的 App、锁屏、关浏览器、断电，都按“暂停”处理。暂停时用时环停止（模考除外，§7）。
- 回来时主界面任务卡变为：

```
│ ┌──────────────────────────┐ │

## 5. 答后反馈、中文解析、同义替换卡

### 5.1 反馈层级（训练模式，选完立即出现）

| 情况 | 默认展示 | 折叠的 |
|---|---|---|
| 快对（≤ 目标用时，未查词） | 一行：“✓ 对 · 14 秒（目标 25）” + 职场一句；**0.8 秒后自动下一题**（可在设置关闭自动跳） | 解析（点“看解析”展开） |
| 慢对 | “✓ 对 · 41 秒（目标 25）· 方法对了，下次可以更快” + 一句提速技巧（来自技巧库，如“先看选项判断题型”） | 完整解析 |
| 错 | “✗ 正确答案 C” + **解析自动展开** | — |
| 查过词 | 在上述基础上加小字“查了 2 个词，这题明天再见一次” | — |

- 颜色只作辅助：对=绿色 ✓ + “对”字；错=橙色 ✗ + “正确答案 C”。**不用红色大面积**。
- 慢对/错 后需用户点“下一题”（不自动跳），按钮在拇指区。

### 5.2 中文解析结构（固定 4 段，每段 ≤2 行）

```
┌──────────────────────────────┐
│ ✗ 正确答案 (C) had finished     │
│ 18 秒 · 目标 25 秒              │
├──────────────────────────────┤
│ 依据  before the board meeting │
│       began yesterday（黄色高亮）│
│ 为什么 “昨天开会之前”已经做完 = │
│       过去的过去 → 过去完成时   │
│ 你选的 (B) has finished：现在完成│
│       不能和 yesterday 连用      │  ← 错因（干扰项套路）
│ 记一招 看到 before + 过去时间，  │
│       先想 had done             │
├──────────────────────────────┤
│ 考点：时态与时间状语 · 掌握 48%  │
│ [看一条工作规则（10 秒）]        │ ← 仅连错≥2
│ [          下一题          ]    │
└──────────────────────────────┘
```
- “依据”段：P7 直接在文章里高亮证据句并在题目栏显示“依据在 邮件 第2段 ↗”（点一下切到文章视图并滚过去）。用户划过依据的，显示“你划的 ✓ 对上了 / 依据在下一句”。
- 只有英文解析的题（open 题，A3 未完成前）：显示英文解析 + 顶部小字“中文解析制作中”。没有任何解析：只显示正确答案和依据（若有）。
- 解析语言风格：大白话，禁止“宾语补足语”等术语单独出现，必须带白话解释（“make + 东西 + 形容词，表示让它变得怎样”）。

### 6.2 复习机制（给 C1 的 UX 约束）

- **统一自动评分**：错/查词/看了解析再答 = Again；对但用时 > 目标 = Hard；对且 ≤ 目标 = Good；对且 ≤ 0.6×目标且本卡已复习过 ≥1 次 = Easy。

- 生词复习**不用“认识/不认识”自评**，改为：英文词 → 四选一中文义（干扰项取同词性同主题）；答对且 ≤4 秒 = Good。生词本可“按主题”浏览，可删除。
- 新题快对且未查词：不建卡（沿用 v2）。
- 复习页一次最多 20 个；积压时按“考频×遗忘程度”排序，只取前面的（§9.3）。

### 6.3 薄弱点攻克（冲刺）

→ ③ 阶梯练 5–8 题（由易到难，连对 3 题提前过关）→ ④ 过关页

过关页：“介词 vs 连词：掌握 52% → 78%。7 天后会再考你 2 题，看是不是真记住了。”

### 6.4 待办复查（错题本）

- 列表按 Part 和考点筛选；每条显示题干前 40 字、错因标签、下次复习时间（“明天”“3 天后”）。

- 不显示“累计错 N 次”这类负面计数，只显示“已复习 2 次，越来越稳”。

### 7.4 预测分展示规则（给 C3 的 UX 约束）

- 永远显示**区间**：“265（235–295）”；区间宽 > 120 分时只显示“估算中，再练 2–3 次更准”。
- 达标把握用百分比 + 一句话：<30% “还需要一段时间”；30–70% “有希望，继续”；>70% “很稳了”。不显示小数。
- 每日波动：日内变化 < 5 分不显示箭头；主界面显示的是**当日开始时的数**，结算页才显示变化（避免做题中途看到下跌）。
- 说明入口“这个分怎么算的？”→ 一段大白话：“根据你做过的题的难度和对错估算，做模考后会校准。范围越窄越准。”

## 9. 断签保护（Streak Freeze）与不惩罚

### 9.1 规则

- **打卡**：当天完成一次任务（任意时长；5 分钟任务按时间完成或做完 ≥5 题）即算。一天的界限：本地凌晨 4 点。
- **断签保护卡 ❄**：连续学 3 天得 1 张；每天最多得 1 张；最多存 2 张。某天没学，第二天打开时自动消耗 1 张，连续天数不断。
- 首次获得时弹一次说明（≤2 行）：“得到 1 张断签保护卡。哪天忙忘了，它会自动帮你保住连续天数。”
- **主要强调“本周学了几天”**（目标：每周 4 天），连续天数是次要信息。周学习天数≥4 在周报里给“出勤满分”。

### 9.2 断签后回来

```
┌──────────────────────────────┐
│ 欢迎回来 👋                     │
│ 隔了 6 天，正常的，工作家里都忙。 │
│ 今天先来 5 分钟，挑了最好上手的。 │
│ [      开始（5 分钟）     ]      │
└──────────────────────────────┘
```
- 不显示“你的连续天数已归零”“你已错过 X 天”。连续天数从 1 重新开始，**“累计学习天数”保留并显示在“进度”**，让努力不清零。
- 回来后的第一个任务难度下调一档（选掌握度较高的考点 + 少量复习），保证能“做得顺”。

### 9.3 复习积压处理（不惩罚的关键）

- 断签后到期卡可能很多：每日任务里复习仍 ≤ 一半；复习页显示的“今天该复习”**最多显示 20**，其余写“其他的会分到接下来几天”。
- 积压超过 3 天量时，C1 按“考频×遗忘程度”挑最值得的，其余平摊到后续 5–7 天（重新排期，不要求用户一次清空）。
- 不出现“逾期”字样、红色数字角标。角标最多显示 “20+”。

## 10. 目标分分档（跳题预算、P7 终点线）如何呈现

### 10.1 档位定义（按阅读目标；数字来自 v1.1 §0 表与 SL11-01/02/03/05，C2 可校准）

| 档位名（界面） | 阅读目标 | 认真做（正确率 70–80% 时） | 跳题预算 | P7 终点线 | P5+P6 用时 | 分 Part 正确率目标 |
|---|---|---|---|---|---|---|
| 入门档（总分约 450–550） | ≤ 225 | 约 30–60 题 | 30–35 题以上 | Q175（单篇做完），多篇全涂 | 25–30 分钟 | P5 约 1/2、P6 约 1/2、P7 单篇约 1/2 |
| 600 档 | 230–300 | 约 50–80 题 | 20–30 题 | Q175（单篇做完）；剩 ≥5 分钟捡“一篇能答”的题 | 25–28 分钟 | P5 约 2/3、P6 约 1/2、P7 单篇约 2/3 |
| 730 档 | 305–370 | 约 85–90 题 | 10–15 题 | Q185（双篇做完） | 22 分钟 | P5 80%、P6 60% |
| 800+ 档 | ≥ 375 | 全做 | ≤ 5 题 | 最后 10–15 题可涂 | ≤ 20 分钟 | P5 90%、P6 每篇错 ≤1 |

用户诊断/模考后得到真实正确率 p，C2 用 v1.1 §0 公式（答对≈A×p+(100−A)×0.25）算出个人的 A，界面显示个人数字而不是表格。

### 10.2 呈现位置

1. **作战卡**（一张卡，4–5 行）：首日结果页、进度页顶部、模考开始前、考前 3 天每天的主界面。示例见 §2 S6。文字永远是行动句（“做到 175 题就停”），不是统计术语。
2. **训练内容过滤**：超出档位的题型/考点不进每日任务；在“自己挑着练”里显示“可选 · 超出你的目标”标签。
3. **档位内专属规则卡**（按档位自动选）：如 600 档在 P6 插入句题出现时提示一次“600 档：插入句可以直接涂，省下时间给语法空（SL11-09）”；P5 词汇题超过 15 秒未答提示“词汇题一眼不会就选一个走（SL11-06）”。每条规则每周最多提示 2 次，可点“不再提示”。
4. **模考题号网格**的终点线（§7.2）。
5. **心理减负文案**固定一句：“没做完是计划内的，不是失败。”（作战卡底部）

### 10.3 档位变化

- 用户改目标分 → 立即重算档位，提示“目标改成 700 了：作战卡已更新（终点线改到 185 题）”。
- 预测分稳定超过目标 30 分（连续 2 次模考）→ 在周报里问一句“已经稳过目标，要不要把目标提高一点？[提到 300] [保持不变]”，不自动改。

## 11. 考前倒排模式

考试日期已设时自动生效；主界面任务卡上方显示阶段条。

```
┌──────────────────────────────┐
│ 距考试 12 天 · 冲刺期            │
│ ▕基础▏强化▕██冲刺██▏考前▏         │
│ 这个阶段：每天复习为主，每周 1 次模考│
└──────────────────────────────┘
```

| 阶段 | 时间 | 每日任务变化 | 复习（给 C1） | 模考 |
|---|---|---|---|---|
| 基础期 | 距考试 > 8 周 | 薄弱点新题为主 | 正常 FSRS（目标保持率 0.9） | 每 3–4 周 1 次（提醒，不强制） |
| 强化期 | 8–3 周 | 加入 P6/P7 混合，速度训练 | 间隔上限 = 距考试天数的一部分（不排到考后） | 每 2 周 1 次 |
| 冲刺期 | 最后 14 天 | 复习占比提高到 60%；只练档位内考点；默认建议 20 分钟（仍可选 5） | 目标保持率提到 0.95；间隔压缩对准考试日 | 每周 1 次 |
| 考前 3 天 | 最后 3 天 | 不出新考点；只复习 + 作战卡演练（10 题按作战卡计时） | 只复习高考频 | 不建议模考 |
| 考试当天 | 当天 | 只显示作战卡 + 考前须知 | — | — |

考试当天屏：
```
┌──────────────────────────────┐
│ 今天考试，加油 💪               │
│ 你的作战卡（600 档）             │
│ · P5+P6 用 28 分钟               │
│ · P7 做到 175 题就停             │
│ · 跳过的题先涂再走                │
│ · 最后 3 分钟全涂满（统一涂 B）    │
│ 考前须知：带身份证、准考证、2B铅笔、橡皮│
│ 考完回来告诉我分数 → [录入成绩]    │
└──────────────────────────────┘
```
- 考试日期过后第一次打开：“考得怎么样？[录入阅读分] [还没出分] [不想说]”。录入后用于 C3 校准，并问“要继续备考下一次吗？[设新日期] [先休息]”。
- 若距考试 < 15 天才开始用：首日流程照常，但 S6 计划文案改为“时间紧：只练最能提分的 3 个考点 + 作战卡”。

## 14. 可访问性要求

- **对比度**：正文 ≥ 4.5:1，大字/图标 ≥ 3:1（WCAG 2.2 AA）；深色模式同样要求。
- **不靠颜色传达**：对/错/已答/当前空/终点线，都同时有图标或文字。
- **点击区域** ≥ 44×44 pt（选项整行 ≥ 48px 高；选项之间间距 ≥ 8px，防误触）；主按钮宽度 ≥ 屏宽 80%（手机）。
- **缩放**：字号到“超大”或系统缩放 200% 时，手机单栏无横向滚动（表格除外）、按钮文字不截断（可换行）。
- **单手操作**：手机上主按钮、文章/题目切换、下一题都在屏幕下 1/3。
- **不施压**：训练计时可隐藏；无倒计时音效；无闪烁（任何闪动 < 3 次/秒）；“减少动画”开启时关闭所有过渡。
- **屏幕阅读器**：所有图标按钮有中文标签（如“退出并保存”“切换到文章”）；选项读作“选项 A，finishes”；答后反馈用 aria-live=polite 播报“正确/错误，正确答案 C”；P6 空位读作“第 132 空，未作答”。
- **键盘**（PC）：全流程可只用键盘完成（§4.2/4.4 快捷键）；焦点框清晰可见；快捷键表在“⋯ → 键盘快捷键”。
- **认知负担**：每屏 ≤ 1 个主按钮、≤ 3 个数字；术语禁用表（FSRS、节点、θ、logit、保持率、bundle、qtype）；所有数字带对比或单位。
- **语言**：界面简体中文；题目英文正文标 `lang="en"`，便于读屏切换发音。
- **年长用户**：默认字号 17px（不默认大字）；首次使用若检测到系统大字，提示一次“可以在 我的 → 字号 里调”。

## 15. 数据事件埋点（答题事件日志）

### 15.1 原则（为 D3 同步做准备）

- **只记事实，不记派生状态。** 掌握度、FSRS 间隔、预测分、连续天数、断签保护卡都由回放事件**重算**，所以多设备合并时只需按时间合并日志，天然无冲突。
- **追加写，不改不删。** 修改设置也是新事件（后写的覆盖前写的）。
- **每条事件可独立理解**（带足够的上下文字段），即使题库版本变了也能回放。
- 本地上限沿用 2 万条；超出时把最早的事件压缩为“快照事件”`state_snapshot`（含当时派生状态 + 已覆盖的事件范围），不直接丢弃。
- 与现有 v2 log 的映射：`answer`→`answer_submit`，`word`→`word_lookup`，`start/end`→`session_start/session_end`，`later`→`item_defer`，`hl`→`highlight`，`rule`→`rule_card_view`，`wordrev`→`review_answer`（type=word），`profile`→`profile_create`，`export`→`data_export`。B2 迁移时写转换器。

### 15.2 公共字段（每条都有）

| 字段 | 说明 |
|---|---|
| `eid` | 事件 ID（UUID v4 或 ULID，按时间可排序优先 ULID） |
| `e` | 事件名 |
| `t` | 客户端时间戳（UTC 毫秒） |
| `tz` | 本地时区偏移（分钟，如 480），用于算“哪一天” |
| `pid` | 档案 ID（本地生成 UUID；同步后绑定账号） |
| `did` | 设备 ID（首次启动生成） |
| `seq` | 本设备自增序号（检测丢失/重复） |
| `sid` | 会话 ID（一次任务/诊断/模考；无则空） |
| `av` | App 版本 |
| `cv` | 题库/内容版本 |

### 15.3 事件列表

| 事件 `e` | 何时 | 额外字段 |
|---|---|---|
| `app_open` | 打开/回到前台 | `from`（cold/resume），`online` |
| `profile_create` | 新建档案 | `target_total`, `reading_target`, `listening_est?`, `exam_date?` |
| `onboarding_step` | 首日每步进入/完成/跳过 | `step`（welcome/target/vocab/diag/result），`action`（enter/done/skip/exit） |
| `target_set` | 设/改目标 | `target_total`, `reading_target`, `listening_est?`, `source`（onboarding/settings/weekly_prompt） |
| `exam_date_set` | 设/改考试日期 | `exam_date` 或 null |
| `vocab_test_item` | 词汇量测试每词 | `word`, `band`, `is_pseudo`, `resp`（know/dont），`ms` |
| `vocab_test_check` | 抽查四选一 | `word`, `choice`, `ok`, `ms` |
| `vocab_test_done` | 测试结束 | `n_items`, `reason`（time/complete/user_end）（估算值由回放重算，可附 `est` 便于调试） |
| `session_start` | 开始任务/诊断/攻克/复习/模考 | `mode`（daily5/daily20/diag/drill/review/mock/free），`planned_ids[]`, `planned_min`, `node?`, `form?` |

## 19. 需 Qing 决定的问题（推荐选项已标 ★）

1. **阅读目标默认怎么算？**
   ★A 问总分 + 可选听力估分；填了听力用“总分−听力”，不确定用“总分×0.45”（依据 v1.1：入门考生听力通常更高，阅读别定太高）。
   B 沿用 v2“总分÷2”。　C 直接让用户填阅读目标。
2. **职场外壳的“收件箱/改稿”要不要做成独立导航入口？**
   ★A 不做独立入口，只在任务内做外壳样式；“复习 → 自己挑着练”里按 Part 自由练。
   B 恢复 v1 原型的 5 个职场 Tab（选择更多，但违背“只选时长”）。
3. **怎样算“今天打卡了”？**
   ★A 完成一次任意时长任务（5 分钟按时间到或 ≥5 题）。　B 必须完成 5 分钟任务全部。　C 做 1 题就算。
4. **词汇量测试形式？**
   ★A “认识/不认识”+ 假词校验 + 少量四选一抽查，3 分钟自动结束。　B 全部四选一（更准但更累，约 5 分钟）。　C 首日不测，改为从做题中慢慢推断。
5. **首日要做多少？**
   ★A 诊断完成即算第 1 天打卡；结果页把“今日 5 分钟”作为主按钮，但明确“明天再练也行”（首日约 9–10 分钟，愿意的再加 5 分钟）。
   B 必须做完诊断 + 5 分钟任务才算首日完成（约 15 分钟）。
6. **训练时答对后怎么切题、用时怎么显示？**
   ★A 快对 0.8 秒自动下一题，慢对/错停下看解析；用时用“灰色用时环”不变红，可隐藏。
   B 一律手动点“下一题”；显示秒数倒计时（更像考试，但压力大）。
