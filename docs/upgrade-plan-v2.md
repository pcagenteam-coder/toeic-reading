# 托业阅读提分原型 升级计划与任务清单（2026-10-20）

见聊天中同名摘要卡；本文件为存档副本。

## 阶段
- v2 交互原型（演示/用户访谈用）
- v3 内容与数据底座（图谱 300 节点、题库生产线、日志规范）
- MVP 小规模上线（50–100 名备考用户，验证提分/小时）

## 核心验证指标
- 每学习小时提分（对照普通刷题）
- 预测分 vs 真实考分误差
- 7 日/30 日留存、每周学习天数
- 薄弱点攻克后同节点正确率保持（7 天后）

## v2 原型 P0
- 开局词汇量测试（含假词），单列商务词认识率
- 一题多标签；Part 6/7 题组建模
- 工作台：目标环(目标刻度+±范围)、达标概率、带时长任务卡
- 进展按完成任务结算；保留开发者视图
- 薄弱点 TOP 榜：正确率+趋势+原因+攻克时长/涨分
- 薄弱点冲刺：追根2题→60秒讲解→阶梯5–8题→过关
## v2 P1
- 点词即查/渐隐注释/生词本；读前关键词；先题后文、划依据、稍后处理；秒审模式；精读解析；复习页（错题/生词/划线/筛选）；考勤表+补卡；每周绩效评估
## v2 P2
- AI 追问；纯刷题开关；进度导出/导入码
## 用户价值判断
- 有把握：诊断+针对练、间隔复习、计时与模考、生词率控制
- 待验证：沉浸是否拖慢、潜移默化够不够快、生成题像不像真题、预测分准确度
- 北极星：每小时涨分
